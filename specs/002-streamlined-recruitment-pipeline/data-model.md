# Data Model: Streamlined Recruitment Pipeline

## Entities & Table Schemas

### 1. `recruitment_drives`
- `id` (UUID, Primary Key)
- `tenant_id` (UUID, Foreign Key)
- `title` (String, required)
- `job_title` (String, required)
- `job_description` (Text, required)
- `cutoff_percentage` (Float, default=60.0)
- `send_rejection_emails` (Boolean, default=False)
- `onboarding_fields` (JSON: e.g. `["experience_years", "referral_source", "phone"]`)
- `status` (String: `draft`, `published`, `completed`, `archived`)
- `created_by` (UUID)
- `created_at` (DateTime)

### 2. `assessments`
- `id` (UUID, Primary Key)
- `drive_id` (UUID, Foreign Key)
- `title` (String)
- `duration_minutes` (Float, default=45.0)
- `questions` (JSON: array of question objects containing `id`, `title`, `type`, `options`, `correct_answer`, `marks`)
- `total_marks` (Float)

### 3. `applications` (Candidate Pipeline Record)
- `id` (UUID, Primary Key)
- `tenant_id` (UUID)
- `drive_id` (UUID, Foreign Key)
- `candidate_id` (UUID, Foreign Key)
- `status` (String: `registered`, `test_in_progress`, `test_rejected`, `l1_eligible`, `l1_in_progress`, `l1_rejected`, `l2_eligible`, `l2_in_progress`, `l2_rejected`, `selected`)
- `magic_token` (String, unique)
- `candidate_profile` (JSON: `{"full_name": "...", "email": "...", "phone": "...", "experience_years": 3, "referral_source": "LinkedIn"}`)
- `test_score` (Float, nullable)
- `test_percentage` (Float, nullable)
- `test_submitted_at` (DateTime, nullable)
- `proctoring_flags` (JSON: `{"tab_switches": 2, "fullscreen_exits": 1, "device_type": "laptop"}`)
- `l1_interviewer_id` (UUID, nullable)
- `l1_claimed_at` (DateTime, nullable)
- `l1_rating` (Float, nullable)
- `l1_feedback` (Text, nullable)
- `l1_decision` (String: `pass`, `reject`, nullable)
- `l1_evaluated_at` (DateTime, nullable)
- `l2_interviewer_id` (UUID, nullable)
- `l2_claimed_at` (DateTime, nullable)
- `l2_rating` (Float, nullable)
- `l2_feedback` (Text, nullable)
- `l2_decision` (String: `pass`, `reject`, nullable)
- `l2_evaluated_at` (DateTime, nullable)
- `rejection_stage` (String: `test`, `l1`, `l2`, nullable)
- `rejection_reason` (Text, nullable)
- `created_at` (DateTime)

### 4. `attempt_answers`
- `id` (UUID, Primary Key)
- `application_id` (UUID, Foreign Key)
- `question_id` (String)
- `submitted_answer` (JSON)
- `is_correct` (Boolean)
- `marks_awarded` (Float)
